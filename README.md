# TFS Furnishing Ecommerce

Premium furnishing ecommerce starter with a React/Tailwind frontend and an Express backend API.

## Structure

- `frontend`: Vite React app with Tailwind CSS, Framer Motion, reusable ecommerce components, routes, cart drawer, wishlist and dummy Shopify-compatible product data.
- `backend`: Express API with product, product detail, quote and consultation endpoints.

## Run Frontend

```bash
cd frontend
npm install
npm run dev
```

## Run Backend

```bash
cd backend
npm install
npm run dev
```

Frontend: `http://localhost:5173`

Backend: `http://localhost:4000/api/health`
